🌉 Paper Bridge Test Data Sheet

Ages 6–10Worksheet1 page, A4

Free printable: a paper bridge data sheet comparing how many coins flat, U-shaped, zigzag and tube bridges can hold, testing each twice for an average, to learn fair testing and structures.

Preview the worksheet

How to use it

  1. Place two stacks of books of the same height 15 cm apart as the “riverbanks”.
  2. Use one sheet of A4 paper each time, folded into the shape on the sheet, and lay it between the books.
  3. Add coins one at a time to the middle of the bridge until it collapses, and record how many it held.
  4. Test each design twice, work out the average and draw a bar chart.
  5. Finally, design your own bridge and go for the record!

Keeping the test fair

  • Use the same paper, the same gap and the same coins every time.
  • Place coins in the middle of the bridge, gently.
  • Change only one thing, the shape, so you know what difference the shape makes.
