🤖 不插電編程方格遊戲

4–10 歲邏輯遊戲1 頁 A4

免費下載列印：不插電編程方格遊戲，用箭咀指令帶小烏龜避開石頭、找到士多啤梨，學習指令次序、迴圈和除錯，零屏幕入門編程思維。

預覽工作紙

點樣用？

  1. 小烏龜 🐢 由起點出發，目標是吃到士多啤梨 🍓，不可以行入有石頭 🪨 的格。
  2. 在下方「我的程式」逐格寫上箭咀：⬆️ 向上、⬇️ 向下、⬅️ 向左、➡️ 向右，每個箭咀行一格。
  3. 寫完後，用手指或小公仔跟住程式行一次，檢查有冇撞到石頭——這就是「除錯」。
  4. 挑戰：找出最短的路線，或用「🔁 重複」把相同的箭咀合併，例如「➡️ ×3」。

按年齡調整

  • 4–5 歲：先不理石頭，只練習由起點行到終點；大人可以讀出指令。
  • 6–7 歲：避開石頭，嘗試用最少步數。
  • 8–10 歲：用迴圈寫最短程式，或自己在空白格加石頭和寶石，出題給家人。
